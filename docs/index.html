Verified Capabilities

Engineered for Speed, Accuracy & Total Privacy

Every capability listed below is implemented directly in the Kotlin + Jetpack Compose codebase and tested via automated JUnit & Robolectric verification suites.

Real-Time CameraX + ML Kit Optical Scanner

Hardware-accelerated CameraX ImageAnalysis pipeline with STRATEGY_KEEP_ONLY_LATEST backpressure. Features Precision Square, 1D Laser Slit, and Full Frame target modes, pinch-to-zoom, tap-to-focus metering, Torch control, and automatic Y-plane low-light exposure boost (< 45 lux).

  • CameraX 1.5
  • Bundled ML Kit 17.3
  • Low-Light Boost

Zero-Permission Photo Library & Self-Test

Decode barcodes from screenshots and saved photos using Android’s system Photo Picker (PickVisualMedia) without requesting storage permissions. Includes multi-angle ZXing rotation/crop recovery (0°, 90°, 180°, 270°) and a built-in Self-Test suite to verify decoding without a physical barcode.

  • PickVisualMedia
  • Multi-Angle ZXing
  • Built-In Self-Test

Offline Anti-Phishing URL Security Shield

Every scanned URL is inspected on-device by PayloadParser.analyzeUrlSecurity() before opening a browser. Flags unencrypted http:// cleartext links, Punycode (xn--) homograph spoofing, raw IPv4/IPv6 hosts, embedded @ authority credentials, suspicious TLDs, and link shorteners.

  • Homograph Detection
  • HTTPS Verification
  • GS1 Checksum

High-Speed Batch & Continuous Inventory

Scan dozens of items in rapid succession with configurable duplicate cooldown suppression, live session counters, and bulk inventory/warehouse note tagging. Export complete batch sessions to RFC-4180 CSV or structured JSON with one tap.

  • Batch Queue
  • Duplicate Guard
  • CSV & JSON Export

Optical QR & 13-Format Generator Studio

Create custom QR codes and 1D/2D barcodes across 10 structured templates (URL, Wi-Fi, vCard 3.0, Retail GTIN, Email, SMS, Phone, Geo, Calendar, Text). Customize error correction (L, M, Q, H), rounded modules, color presets, and export up to 1536px PNGs.

  • 13 Symbologies

  • HD PNG Share

Local Room SQLite Optical Vault

All scanned and generated records are persisted strictly on-device inside prism_scan_vault.db. Features instant full-text search across payloads and notes, 9 category/security filters, favorite bookmarking, and granular vault purge controls.

  • Room SQLite 2.8

Zero-Trust Local Architecture

Privacy by Engineering, Not Just Policy

Verified directly from app/src/main/AndroidManifest.xml and app/build.gradle.kts.

Verified Offline Data Handling

  • No Internet Permission: QRYPT does not declare android.permission.INTERNET. The Android OS prevents the app from opening network sockets or transmitting data off your device.
  • Bundled On-Device ML Models: Uses com.google.mlkit:barcode-scanning:17.3.0 (bundled model) and com.google.zxing:core:3.5.3 so scanning works immediately on first launch in Airplane Mode.
  • Local SQLite & DataStore Sandbox: History and preferences stay inside your private app storage (prism_scan_vault.db) with 1-tap Vault Purge at any time.
  • Scoped File Exports: CSV, JSON, and PNG exports use androidx.core.content.FileProvider (android:exported="false") only when you explicitly tap Share/Export.

Permissions Explained in Plain Language

  • android.permission.CAMERA (Optional Runtime): Used strictly to analyze live viewfinder frames in volatile memory. If denied, you can still scan images from your photo library, use the Self-Test suite, browse the Vault, and create codes in Studio.
  • android.permission.VIBRATE (Normal Install-Time): Triggers a subtle haptic pulse when a barcode locks onto the reticle (can be toggled off in Settings).
  • Zero Storage Permissions: QRYPT uses the system Android Photo Picker (PickVisualMedia) and never requests READ_MEDIA_IMAGES or READ_EXTERNAL_STORAGE.
  • Zero Tracking Permissions: Never requests Location, Contacts, Microphone, Phone State, SMS, or Bluetooth permissions.

Frequently Asked Questions

Everything You Need to Know

Does QRYPT require an internet connection to scan or generate barcodes?
No. QRYPT is 100% offline. It does not even request the android.permission.INTERNET permission in its AndroidManifest. Both Google ML Kit Barcode Scanning (bundled model) and ZXing Core run entirely on your device’s processor.
How can QRYPT scan photos from my gallery without requesting storage permissions?
QRYPT uses Android’s modern system Photo Picker (ActivityResultContracts.PickVisualMedia). When you tap Photo Library, the Android OS presents its built-in picker and grants QRYPT temporary read access only to the single image you choose, keeping the rest of your photo library completely private.
How does the offline URL anti-phishing analyzer work?
Whenever a QR code or barcode contains a link, PayloadParser.analyzeUrlSecurity() inspects the URI structure locally. It flags unencrypted http:// protocols, Punycode (xn--) internationalized homograph attacks, raw IPv4/IPv6 hostnames, embedded @ authority spoofing, high-risk top-level domains, and URL shorteners before launching any browser intent.
Why is the internal Android package identifier hidden from the user interface?
To keep the interface clean and consumer-friendly, the Settings screen displays only the product identity (QRYPT • Scan Smarter. Instantly.), developer (Arnobrazz), and version (1.0.0). Under the hood, applicationId = "com.arnobrazz.qrypt" remains intact in app/build.gradle.kts for standard Android installation and upgrades.
What Android versions are supported?
QRYPT supports Android 7.0 Nougat (API 24) through Android 16 (API 36), including foldables, tablets, and Android 12+ Material You Dynamic Color themes.
How can I contribute, report a bug, or disclose a security issue?
Read our Contribution Guide and open an issue or pull request on GitHub Issues. For security vulnerabilities, please follow our Security Policy and email arnobrazz.dev@gmail.com.

Engineered for Precision & Privacy

Every feature in QRYPT runs 100% locally on your Android device with zero network dependencies.

Dual-Engine Optical Pipeline

Combines Google ML Kit Barcode Scanning for real-time CameraX streams with ZXing Multi-Format Reader (Hybrid + GlobalHistogram binarizers) for static images.

Offline URL Anti-Phishing

Flags unencrypted HTTP links, Punycode (xn--) homograph spoofing, raw IP addresses, embedded @ credentials, and shorteners before opening any link.

13 Symbologies & GS1 Lookup

Decodes and generates QR, Aztec, Data Matrix, PDF417, EAN-13/8, UPC-A/E, Code 128/39/93, Codabar, and ITF with automatic Modulo-10 checksums and GS1 country lookup.

Batch Queue & CSV/JSON Export

Capture items in rapid succession with configurable duplicate cooldowns, bulk-tag inventory notes, and export RFC-4180 CSV or structured JSON files.

Zero-Permission Photo Picker

Scan barcodes from screenshots and gallery photos using Android's system Photo Picker (PickVisualMedia) without requesting storage permissions.

Zero Internet Permission

QRYPT does not declare android.permission.INTERNET. No camera frames, scan history, or telemetry can ever leave your device.
